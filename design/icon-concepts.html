zero — icon concepts

A — cursor zero
the counter of the 0 is a terminal block cursor. zero + terminal in one glyph. the blue is the only color in the app's chrome, so dock and app match.
B — slashed zero
the programmer's zero, straight from monospace fonts. instantly reads "dev tool". safe, classic, monochrome.
C — diff zero
split down the middle, halves offset: old left, new right — a split diff as a glyph. cleverest concept, but reads as "broken" at 32px.
D — bare ring
just a thin zero, nothing else. the most "zero" of them all — but also anonymous; could be any minimal app.
